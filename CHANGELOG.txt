AION 2 CHARACTER TRACKER - CHANGELOG
====================================
All data is stored only in each person's own browser (localStorage).
Updating the site never resets anyone's saved characters.


2026-10-19 (newest 11)
----------------------
- Pages sidebar on the left: Character Tracker (the existing page) and a new
  Pet Tracker page. The page you were on is remembered.
- Pet Tracker: list of 200 pets with Elyos / Asmodian / Abyss tick or cross,
  a "View location" link, genus type and notes. Tick the box on the left to
  hide a pet you have; Find box and genus filter; "Show hidden pets" /
  "Hide ticked pets again" button. Ticks are saved in your browser.
- With the membership switch off, the Energy cap shows 560 instead of 840
  (characters on the standard cap only).


2026-10-18 (newest 10)
----------------------
- Membership icon now has a transparent background (cleaner on both light and
  dark mode) and is a little larger.


2026-10-18 (newest 9)
---------------------
- Membership switch (with the membership icon) in the Show on page card. When
  off, Odyle Shop Purchases are hidden on every character and left out of
  Estimated Income and the Kina cost. On by default; remembered in your
  browser.
- Small info (i) icons: Est. Kina (counts current energy, plus morphs and shop
  purchases left; not energy that recharges later) and Shop Purchases
  (membership required, sold by the Windbreeze Merchants).

2026-10-18 (newest 2)

2026-10-18 (newest)
-------------------
- Game lookup: item level and class icon can be pulled automatically from the
  official AION 2 character data (through a small Cloudflare Worker relay).
  Pick Region and Server when adding a character and Add character fills in
  the item level and class icon. Each character also has a Game lookup box in
  its Estimated Income section (Update item level button).
- Item levels of looked-up characters refresh automatically when the page is
  opened, at most once every 30 minutes per character.
- A server must be picked whenever a region is chosen. Class dropdown removed
  from Add a Character (the class comes from the lookup).
- Estimated Income details moved into an info (i) icon next to the heading.
- Manual item level box is still there as a fallback.


2026-10-18 (earlier)

  3/8) and is disabled once the limit is reached.

Earlier updates
---------------
Characters and energy
- Odyle Energy and Charged Energy per character, with a recharge of +15 every
  3 hours on the hour (Energy cap 840, Charged Energy cap 2000).
- Odyle Energy Cubes shown at 40 and 80 energy each.
- Spend buttons for Expedition and Transcendence (40 or 80) that also add to the
  server run count.
- Sync buttons for Energy and Charged Energy, plus an Add Charged Energy box.
- Collapsible character cards and a collapsible Add a Character card.
- Character names larger; red Remove button.

Weekly and daily trackers
- Nightmare tickets with Extra count (cap 14) and Ascension Trial entries with
  Extra count (cap 30), including reset handling.
- Odyle Morph (4 per character per week) with Morph All.
- Odyle Shop Purchases (20 per character per week) with remove-by-amount.
- Weekly Odyle Energy (shared, 16 per server) with a custom-amount box.
- Daily Dungeon (shared) with Use, Use All and an amount box.
- Daily and weekly reset countdowns at the top of the page.
- Show on page tickboxes to hide Add a Character, Weekly Odyle Energy,
  Daily Dungeon and Server Run Count.

Kina and server run count
- Estimated Kina income per character from item level and highest run, based on
  current energy plus Morph and Shop Purchases left.
- Server Run Count for Expedition and Transcendence with the cumulative Kina
  reduction tiers, runs until the next threshold, and a reset timer.
- Shared Weekly Odyle Energy crafts count toward the first character's estimate.

Page and hosting
- Page titled "Aion 2 Character Tracker" with a moon favicon.
- Backup and transfer panel: Export and Import by copy and paste.
- Hosted on GitHub Pages with browser-only data storage.
